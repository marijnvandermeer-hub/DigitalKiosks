## Key reproduction checks

The clean pipeline reproduces the core sample and regression dataset sizes used in the report:

- Total respondents: 1,303
- Ownership GEE: 14,312 respondent-item rows
- Underutilisation GEE: 5,257 owner-item rows after the minimum 10 owners per city-item rule
- Adjusted ownership probabilities by income: 33.3%, 36.4%, 40.8%
- Adjusted underutilisation probabilities by income: 47.3%, 46.9%, 46.3%

These checks match the final analysis outputs used to draft the report.
